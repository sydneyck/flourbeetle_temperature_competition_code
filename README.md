# flourbeetle_temperature_and_competition_code
This repository contains all of the data and code necessary to reproduce the analyses from "Interspecific competition eliminates the effects of rapid evolution to temperature on population dynamics".

# Repository contents

- **Data**: Folder contains datasets used for analyses

- **Script**: Folder contains R code to reproduce analyses

- **Output**: Folder contains manuscript figures (generated by R code in `Script`)

- **flourbeetle_temperature_and_competition_code.Rproj**: R Project for setting the working directory and organizing code in RStudio

- **README.md**: Summary of GitHub repository

- **.gitignore** : Default version created when initializing the Git repository
